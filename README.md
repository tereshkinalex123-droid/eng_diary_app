LINGUAFLOW — Система изучения английского с интервальным повторением
Веб-приложение для изучения английского языка с системой интервального повторения, дневником и Telegram-интеграцией.

СТЕК ТЕХНОЛОГИЙ:
Backend: Python (pillow, aiogram), Django, Django REST Framework
DB & Cache: PostgreSQL, SQLite (разработка), Redis
Asynchronous Tasks: Celery
Tools & Frontend: Bootstrap, AJAX
Integrations: Telegram Bot API, SMTP (email уведомления)

ЧТО БЫЛО СДЕЛАНО:
1) Разработка архитектуры бэкенда:
  - Спроектировал CRUD-логику для подприложений (accounts, vocabulary, records, bot).
  - Реализовал систему интервального повторения SRS (бизнес-логика).
  - Настроил загрузку карточек без перезагрузки страницы через AJAX-запросы к API.
  - Реализовал аутентификацию пользователей с использованием стандартной Django-аутентификации
2) Работа с данными и миграции:
  - Настроил взаимодействие с СУБД PostgreSQL через Django ORM.
  - Добавил сигналы для создания прогресса новых карточек.
3) Очереди задач и фоновые процессы:
  - Реализовал фоновое обновление ежедневных серий и периодические задачи с помощью Celery и Redis:
    - отправка напоминаний о пропущенных днях (три раза в день
    - проверка новых записей в дневнике
    - отправка уведомлений в Telegram 
4) Деплой и развертывание:
  - Развернул приложение в продакшн на Render с использованием PostgreSQL и Redis как managed-сервисов.
5) Интеграция с Telegram:
  - Разработал Telegram-бота на aiogram для создания карточек и записей в мессенджере.
  - Реализовал привязку аккаунта пользователя через токен.
  - Настроил отправку уведомлений о потере стрика и новых записях.
